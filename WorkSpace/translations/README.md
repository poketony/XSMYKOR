## 편집 규칙

- 검수할 때는 `[KOR]`을 수정하고 `[JPN]`·ID·출처·소유 심벌·프레임을 보존한다.
- 기존 화면 문자열은 `[KOR]`에 공백 외 내용이 있을 때만 한국어를 적용한다. 없거나 빈 문자열·공백뿐이면 기존 일본어를 유지한다.
- 번역 전 [사용자 지침](korean-guidelines.md), [인물 말투](character-voices.md), [DB 참고 방식](../../codex-lab/analysis/translation-notes/database-reference.md)을 확인한다. 스킬 설치 경위는 [준비 기록](../../codex-lab/analysis/translation-notes/preparation-status.md)에 있다.
- 같은 원문도 위치별 ID를 유지한다. 스크립트 대사는 루트 장면과 소유 프레임·행 번호 순으로 정렬했으나 분기·콜백까지 단순한 배열 순서라고 가정하지 않는다.
- JSON의 `\n`은 문자열 안의 실제 줄바꿈이다. 대사 144개의 원래 개행 수와 문단 시작을 보존했다.

487개 텍스트 객체 중 실제 한국어로 번역한 객체는 446개다. 나머지는 원래 빈 필드 6개, 날짜 타이핑·기술 식별자 유지 15개, 완성 문장에 연결한 글자 애니메이션용 글리프 정의 20개다. 대사 144개를 합쳐 한국어 번역을 작성한 항목은 590개다. 이를 구별한 검증 결과는 [verification.json](../../codex-lab/analysis/translation-verification.json)에 있다.

## 글자 애니메이션과 레코드 구분자

6장의 `animated_glyph_definition` 20개는 같은 글자를 다른 위치에서도 재사용하는 부품이다. `phrase_translations`가 가리키는 `ch06:text315`·`ch06:text334`에 완성 문장의 한국어를 넣었다. 이 부품은 `apply_independently: false`이므로 일본어 글자마다 번역 문자열을 따로 적용하지 않는다. 리빌더는 완성 문장으로 배치별 한국어 심벌을 생성하고 기존 깊이·행·클립 구조를 유지한다. 실제 연출 화면은 추가 검수가 필요하다.

`--- RECORDSEPARATOR ---`는 FFDec 추출기가 글꼴·위치 레코드 사이에 넣은 구분자다. 화면에 표시할 문자로 취급하지 않는다. 1장의 정적 첫 독백은 같은 내용의 스크립트 4문단을 참조하며 한국어 문단을 함께 보존했다. 이 JSON을 그대로 FFDec 텍스트 가져오기에 넘길 수 있다는 뜻은 아니다.

## 기존 첫 독백과 실행본

[chapter01-opening.json](chapter01-opening.json)은 기존 빌더와 호환되는 `txt1`~`txt4`의 4항목 입력이다. 장 전체 데이터의 같은 대사와 원문·번역을 일치시켰다. 초기 테스트의 문장을 검수한 상세 판단은 [검수 기록](../../codex-lab/analysis/translation-notes/review-notes.md)에 있다.

프로젝트 루트의 [rebuild.bat](../../rebuild.bat)은 `chapter01.json`~`chapter06.json`을 장별 입력으로 사용한다. 대사 스크립트·정적 UI·동적 설명문·6장 글자별 연출을 반영하며, 빈 `[KOR]`은 일본어를 유지한다. 정적 텍스트의 레코드 구분자는 위치·서식 단위로 처리하고 화면 글자로 삽입하지 않는다.

장 전체 리빌드를 위해서는 `chapter01.json`의 해당 항목을 편집한다. `chapter01-opening.json`은 이전 첫 독백 전용 시험 빌더의 입력이며 새 장별 리빌더는 읽지 않는다. 현재 두 파일의 첫 독백은 같지만 장별 데이터만 수정하면 이전 시험 입력과 달라질 수 있다.

과거 테스트 실행본과 번역 조립용 중간 파일은 저장소 정리 때 삭제했다. 현재 JSON이 검수할 번역의 기준이며, 최신 문구의 화면 검수는 아직 하지 않았다. 새 문구의 글리프·줄바꿈·스크롤·타이핑·NEXT·음성 동기화는 다시 빌드할 때 검증해야 한다.

## 음성 전용 장면 검토용 파일 목록

[오디오 파일 목록](../../codex-lab/analysis/audio-only-scenes.md)과 [JSON](../../codex-lab/analysis/audio-only-scenes.json)에 스크립트 대사가 검출되지 않은 56개 장면의 오디오 파일 76개를 정리했다. 파일은 복사하거나 변경하지 않았으며 경로와 해시를 확인했다. 음악·효과음을 청취로 분리한 확정 음성 목록은 아니므로 목록의 후보 분류를 함께 확인한다. 음성을 추측해 전사하거나 번역문으로 채우지 않았다.

## 검증과 재현

원본 6장의 해시, 스크립트 892개의 해시, 631개 항목의 원문·ID, 기존 첫 독백의 원문 보존과 동기화, 독립 번역문의 일본어 잔존, 대사 개행·인용부호·제어문자, 오디오 경로·해시를 검사했다. 숫자를 한국어 수사로 바꾼 경우와 원문 표기의 특이점은 [검수 기록](../../codex-lab/analysis/translation-notes/review-notes.md)에 남겼다.

초기 일본어 문자열 목록 637행도 대조했다. 631개 항목과 화면에 출력하지 않는 디버그 `trace("トーク")` 6개로 모두 설명된다. 추출 목록의 다른 표시 문구가 번역 목록에서 빠지지 않았는지 확인했다.

로컬 분석 도구가 있는 프로젝트 루트에서 다음 명령으로 확인할 수 있다.

```powershell
python -B -X utf8 codex-lab/verify_full_translation.py
```

이 명령은 현재 `WorkSpace/translations`의 결과를 `codex-lab`의 추출·분석 자료 및 원본 SWF와 대조한다. SWF를 재빌드하지 않는다. 실제 재생 검수와 독립 감수는 이번 텍스트 검증에 포함되지 않는다.
