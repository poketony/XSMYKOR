# 미싱 이어 인물 말투 참고

사용자가 전달한 XS2 작업 경험과 XS1 한국어 용례 관찰을 옮긴 참고 기준이다. 미싱 이어 일본어 원문·음성을 전 구간 대조해 확정한 말투표는 아니다. 실제 발화 상대·시점·공적/사적 상황을 먼저 확인한다. DB의 인물 성격 설명만으로 어미를 확정하지 않는다.

| 화자 | 관계별 참고 | 피할 단순화 |
| --- | --- | --- |
| 시온 | 알렌·케이오스·모모에게 기본 반말. 걱정·장난·기술 설명의 차이를 살림 | 모두에게 같은 반말, 항상 귀엽거나 딱딱한 말투 |
| 알렌 | 시온에게 `주임님`과 존대. 실무의 침착함과 사적인 당황을 구분 | 매번 말더듬 추가, 속마음을 직접 발화로 취급 |
| KOS-MOS | `시온`으로 부르며 `~습니다/~입니까`. 특징적 도움·기쁨 표현은 지침 예문 참고 | `시온 님` 추가, 모든 문장을 단답 보고체로 만듦 |
| 모모 | `시온 씨` 등 존대. 자기 이름을 1인칭으로 쓰는 용례가 있으며 기술 보고도 함 | 전부 `저`로 교체하거나 항상 자기 이름·유아어를 넣음 |
| 지기 | 짧고 침착한 판단·보호 명령 | 거칠게 보이도록 욕설을 추가 |
| Jr. | 직설적이고 활동적인 반말. 전문 지식·지휘 상황도 고려 | 외형을 근거로 유아어 추가 |
| 케이오스 | 부드러운 말투, 상대에 따른 높임을 확인 | 신비롭다는 이유로 예언체·전지적 해설 추가 |
| 메리 | XS1 번역에 경상도 계열 용례가 있음 | 미싱 이어 근거 없이 모든 대사를 같은 사투리로 확정 |
| 셸리 | 표준어의 차분한 설명·보고, 존대 | 메리와 말투를 합침 |
| 해머 | 기존 `~슴다/~임까/~십쇼`와 해요체 용례 | 보통 존대나 토니의 반말로 일괄 통일 |
| 토니 | 능청스럽고 친근한 반말 용례 | 해머와 같은 말투로 통일 |
| 도크투스 등 미싱 이어 주요 인물 | 이 작품의 실제 원문·음성과 상대별 관계를 새로 확인 | DB 설정을 말투·지식 범위의 확정 근거로 사용 |

시온이 승무원·처음 만난 성인에게 쓰는 높임은 개별 확인한다. 나이·성별·외형만으로 존대 방향을 정하지 않는다. 목록에 없거나 등장하지 않는 인물 때문에 새 번역 작업을 만들 필요는 없다.

새 장면에서 `화자 → 청자 / 장면·대사 ID / 시점·상황 / 호칭·어미 / 원문·음성 근거 / 확정 또는 가설`을 기록한다. 말투가 바뀌면 상대·감정·상황에 이유가 있는지 확인한다. 다른 관계까지 같은 어미로 고정하지 않는다.

수동 조회한 출처는 `C:/Users/JO/XS2KOR/codex-lab/xenosaga-db-reference/character_voice_notes.md`다. 그 문서는 XS1 한국어 TXT를 읽은 관찰과 사용자 승인 예문을 구별한다. 이 프로젝트에서 XS1 원문·음성 전체를 새로 검증했다는 뜻은 아니다. 해시는 [참고 자료 기록](../../codex-lab/analysis/translation-notes/reference-sources.json)에 보존하며 자동 동기화하지 않는다.
