# 번역 작업 공간

[translations](translations/README.md)에 1~6장 번역 JSON, 첫 독백 입력, 번역 지침과 인물 말투 기준을 둔다. 검수할 때는 `[KOR]`을 편집하고 원문·ID·출처를 보존한다.

추출한 이미지·소리·텍스트·스크립트·XML은 `codex-lab/extracted/chapter01`~`chapter06`에 있다. [구조 분석](../codex-lab/analysis/README.md), [추출 안내](../codex-lab/analysis/extraction.md), [DB 참고 방식](../codex-lab/analysis/translation-notes/database-reference.md), [음성 전용 장면 오디오 목록](../codex-lab/analysis/audio-only-scenes.md)도 `codex-lab`에서 관리한다.
